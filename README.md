# Webツール集 取扱説明書

本アプリケーションは、画像処理・音声合成・テキスト処理・データ変換を行うブラウザ向けユーティリティツール集です。

---

## 概要と動作仕様

- **処理方式**: 画像変換・音声合成・ファイル解析などの主要処理はブラウザのクライアントサイド（Canvas API, Web Audio API, Web Workers等）で実行されます。
- **UI表示**: ダークテーマおよびライトテーマの切り替えに対応しています。
- **ショートカットキー**:
  - `Alt + M` または `[` : サイドバーメニューの開閉
  - `Ctrl + Z` : スプライト切り出しにおける直前操作の取り消し
  - `Ctrl + マウスホイール` : スプライト編集キャンバスの拡大 / 縮小
  - `Esc` : スプライト切り出しの全画面最大化モードの解除

## 機能一覧と操作手順

### 1. 画像・グラフィック処理

#### スプライトシート切り出し
スプライト画像からキャラクターやエフェクトの各コマを切り出し、連番ファイルとして保存します。
- **画像読み込み**: スプライトシート画像をドラッグ＆ドロップまたはファイル選択で読み込みます。
- **背景設定**:
  - アルファ透明: 透過PNGなどの透明領域を認識して自動切り出しを行います。
  - 指定単色背景: スポイトまたはカラーピッカーで背景色を指定し、許容値を設定して透過処理を行います。
- **切り出し操作**:
  - クリック: 連続したピクセル領域を自動検出して最小矩形を抽出します。
  - ドラッグ領域選択:
    - 自動吸着フィット: 選択枠内の不透明ピクセル群を自動で1つの矩形に統合します。
    - 枠のまま切り出し: ドラッグした指定サイズで切り出します。
- **表示操作**:
  - ウィンドウ拡大ボタン: 編集エリアを全画面表示に切り替えます（Escキーで解除）。
  - 表示倍率: 25%〜800%のズーム、100%等倍、フィット表示が可能です。
- **並び順とプレビュー**:
  - 抽出リスト内の並び順をドラッグ＆ドロップまたは矢印ボタンで変更できます。
  - 自動整列（上から下・左から右）および反転機能があります。
  - 連番アニメーションプレビューで再生速度（FPS）を指定して動作確認が行えます。
- **保存**: 出力ファイル名を指定し、「ZIP一括保存」で連番PNG画像（`001.png`, `002.png`...）を出力します。

#### YouTubeサムネイル取得
YouTube動画のサムネイル画像を取得・保存します。
- **取得**: 動画URLまたは動画ID（11桁）を入力して取得します。
- **解像度**: 最大解像度（1080p）、高画質（HQ）、中画質（MQ）、標準画質（SD）を表示します。
- **保存**: 各解像度をPNG/JPG/WEBP形式で個別保存、または全解像度を一括ZIP保存します。

#### 画像形式一括変換
複数の画像形式を相互に一括変換します。
- **対応形式**: PNG, JPG, WEBP
- **設定**: JPG/WEBP形式の場合は品質（圧縮率 1〜100%）の指定が可能です。
- **出力**: 単品ダウンロードまたはZIP一括保存に対応しています。

#### 透過画像余白自動削減
透過PNGまたはWEBP画像の周囲にある透明ピクセルを検出し、描画部分のみを自動トリミングします。
- **出力仕様**: 元ファイル名の末尾に `_c` を付与して出力します。

#### クロマキー背景透過
画像内の特定背景色を透過処理します。
- **設定項目**: 基準色指定（スポイト対応）、許容度（Color Tolerance）、境界スムーズ度、エッジ浸食（フリンジ除去）。

#### SVG余白トリミング
SVGベクターデータの外周余白を自動測定し、ViewBox属性を最適化します。

### 2. 音声・DAW連携

#### スペクトログラム音声生成
画像の明暗と色彩を周波数成分に変換し、WAV音声ファイルを合成します。
- **パラメータ設定**:
  - 再生時間: 1秒〜30秒
  - 最低周波数 / 最高周波数: 20Hz〜22050Hz
  - 周波数スケール: 線形（Linear） / 対数（Logarithmic）
  - コントラスト調整: 明暗の強調度
- **保存と利用**:
  - 保存ファイル名を指定してWAV形式でダウンロードできます。
  - 生成されたWAVファイルはDAWソフトウェア（REAPER, FL Studio, Ableton Live等）のタイムラインへ直接ドラッグ＆ドロップして配置可能です。

#### 音素データベース解析
音声合成用の音素データベース（JSONファイル）の構造解析と可視化を行います。
- **可視化機能**:
  - 五十音カバレッジ率および収録回数ヒートマップ
  - 音域ピッチ分布（最低音・最高音・頻出音高）
  - 収録楽曲・発音リストの表示
- **複数キャラ読み込み**: 複数の音素DBをタブで切り替えて比較可能です。

#### REAPER / 音素DB パス編集
REAPERプロジェクトファイル（`.rpp`）および音素DB（`.json`）内のファイルパスを一括置換します。
- **機能**: ドライブレターの変更、フォルダ階層の移行、差分ログの確認。

### 3. テキスト・文字列処理

#### 短縮URL展開
短縮URL（bit.ly, t.co, x.gd等）のリダイレクト先を追跡し、最終転送先URLを表示します。

#### 文字数カウンター
入力されたテキストの計量と分析を行います。
- **集計項目**: 文字数（空白含む/除く）、行数、原稿用紙換算枚数（400字詰）、バイト数（UTF-8 / Shift_JIS）、読了予測時間。
- **文字種分析**: 漢字、ひらがな、カタカナ、英数字、記号の割合グラフ。
- **入力支援**: 特殊記号および顔文字パレット。

#### Markdownエディタ
Markdownテキストの編集とリアルタイムプレビューを行います。
- **機能**: 編集ツールバー、HTMLプレビュー表示、Markdown（`.md`）およびHTML（`.html`）形式での保存。

#### 文字化けシミュレータ＆復元
文字コード（UTF-8, Shift_JIS, EUC-JP, ISO-2022-JP）の誤認による文字化けの再現および復元を試行します。

#### 日本語URLエンコード / デコード
パーセントエンコーディングと日本語平文の相互変換を行います。

#### PDF画像抽出・変換
PDFファイルの各ページをレンダリングし、PNG/JPG画像として抽出します。

#### 1バイトフォントコード変換
1バイト文字コードの対応表に基づくテキスト変換を行います。

#### ローマ字かな変換
ひらがな・カタカナ・ローマ字（ヘボン式/訓令式）の相互変換を行います。

## 開発・実行手順

### 環境要件
- Node.js 18以上
- npm

### コマンド
```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動（ポート 3000）
npm run dev

# 本番用ビルド（distフォルダに出力）
npm run build
```

## GitHub Pages での公開手順

本アプリケーションは Vite + Tailwind CSS を使用しているため、**ビルド後の成果物（`dist` ディレクトリ）** を公開する必要があります。
リポジトリ直下の未ビルドの `index.html` をそのまま配信すると、CSS やモジュール JavaScript が適用されず UI が崩れます。

### 推奨方法: GitHub Actions による自動デプロイ（設定1分）

リポジトリ内に `.github/workflows/deploy.yml` を用意しているため、以下の設定を行うだけでプッシュ時に自動でビルド＆公開されます。

1. GitHub のリポジトリ画面を開きます。
2. **Settings** タブをクリックします。
3. 左メニューの **Pages** を選択します。
4. **Build and deployment** の **Source** を「**GitHub Actions**」に変更します。
5. `main` ブランチにファイルをプッシュすると、自動的にビルドが実行され正常なレイアウトで公開されます。
